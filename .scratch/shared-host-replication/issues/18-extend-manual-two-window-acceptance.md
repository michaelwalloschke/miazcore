# Extend the manual two-window acceptance

Type: wayfinder:prototype
Status: resolved
Blocked by: [Prototype the dual-window Diagnostic World experience](07-prototype-dual-window-diagnostic-experience.md), [Specify the replication evidence contract](11-specify-replication-evidence-contract.md), [Design the Remote Avatar presentation boundary](15-design-remote-avatar-presentation-boundary.md)

## Question

What short, repeatable manual macOS checklist extends the existing Diagnostic
World acceptance to confirm two distinct windows, Fixture identities, Remote
Avatar Marker readability, heading/pose distinction, role turn visibility, and
clean disappearance without replacing automated evidence?

## Decision boundaries

This is a human-facing prototype and contract, not a second broad acceptance
program or a substitute for semantic sidecars and controlled capture.

## Answer

[Manual two-window acceptance](../research/18-manual-two-window-acceptance.md)
defines the short, fail-closed macOS checklist and its SHA-bound, closed
attestation template. It confirms visual readability and local controls while
leaving Remote Avatar lifecycle, timing, and pose claims to automated evidence.
